Modular Context-Aware Text-to-SQL Engine personal project
Python · LangGraph · LangChain · SQL
  • Architected a fully modular, self-correcting Text-to-SQL engine using LangGraph and LangChain, translating natural language queries into SQL through a reusable four-stage pipeline: Intent Recognition, Contextual Rephrasing, Table Selection, and SQL Generation. Every stage is an independent, swappable component.
  • Implemented a self-correcting execution loop: generated SQL is executed against the database, and if the query returns an error or an empty result set, the engine captures the failure, suppresses the raw error from the user, and automatically re-enters the pipeline with the failure context to regenerate a corrected query.
  • Engineered a long-term memory system backed by LangGraph's persistent state: incorrect table selections and failed query patterns are written to long-term memory and injected as context before every subsequent Table Selection step. The engine learns from its own mistakes within a session and across sessions, progressively reducing wrong-table errors.
  • Built an LLM-powered result validation layer that evaluates whether the returned data actually satisfies the user's original intent. If the result is semantically insufficient or incomplete, the engine triggers a re-generation cycle with enriched context rather than surfacing a misleading answer.
  • Integrated a Human-in-the-Loop (HITL) gate that intercepts any SQL classified as a mutation operation (UPDATE, INSERT, DELETE, DROP) and routes it for explicit user confirmation before execution, preventing irreversible data changes from running autonomously.
